# Security Policy

**Angelito Systems** takes the security of our software and users seriously.

---

## Supported Versions

| Version | Supported          |
| :------ | :----------------- |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in `@angelitosystems/nest-auth` or `nest-auth-kit`, please do **NOT** open a public issue on GitHub.

Instead, please send an email to:
**security@angelitosystems.com**

Include:
1. Description of the vulnerability and potential impact.
2. Steps to reproduce or proof-of-concept code.
3. Relevant environment details (Node.js version, NestJS version, Adapter used).

### Security Response Process

- We will acknowledge receipt of your vulnerability report within 48 hours.
- A private investigation will take place to assess the severity and identify a remediation patch.
- We will coordinate with you regarding the public disclosure date once a patched version is published.
- Security advisories and patches are distributed through GitHub Releases and npm notices.
